# Pavan Kalyan Portfolio

Static recruiter-facing portfolio for Pavan Kalyan, Senior Software Engineer specializing in data platforms, measurement, segmentation, workflow orchestration, and cloud-native reliability.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080` in a browser.

## Publish with GitHub Pages

In the repository settings, enable **Pages** and choose **Deploy from a branch** with the `main` branch and `/ (root)` folder.
